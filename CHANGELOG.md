# Changelog

## 0.5.1

- Add an explicit one-command source setup helper, offline/manual install instructions, and platform-specific checksum steps.
- Add a reproducible fictional dashboard demo and original public screenshots with documented provenance.
- Add keyword/search-intent research, five practical guides, workflow diagrams, and a 30-day organic discovery plan.
- Use clearer advisory wording for the connection-count rule and document its 20-connection threshold and false-positive limits.
- Run read-only source validation on pushes and pull requests; retain manual native builds and explicit release publishing.
- Keep an official version-specific Python license fallback for hosted builders; inspect decompressed packaged code without cross-version deserialization.
- Exclude CPython compiler configuration containing vendor build-machine paths from POSIX native packages; retain the strict artifact privacy gate.

## 0.5.0 — extensible product beta, unpublished

- Private custom CLI and compatible model-server profiles with explicit consent, stdin prompts, schema constraints, and independent result validation.
- Fictional connection tests in the CLI and dashboard; connection results never become host findings. Clear authentication, quota, unsupported-version, and timeout errors.
- Gemini inference contract with a dedicated vendor profile, denied tools, disabled hooks/extensions/memory, and administrator-policy conflict checks. Shared credentials are never copied; vendor sign-in remains required.
- Fixed Gemini's Windows npm bundle entry-point discovery. Codex and Claude contracts were live-tested using fictional evidence only.
- Deterministic portable Python launcher for supported desktops, with private staging, member validation, privacy checks, and a synthetic self-test. Python and psutil are explicit external prerequisites.
- Bundled AI setup instructions and improved Windows desktop console handling; native Windows/Linux x64 builds and six native target definitions.

## 0.4.0 — direct AI review, unpublished

- AutoWork-style explicit provider adapters, stdin prompts, bounded anonymous evidence, structured results, and no fallback.
- Local Ollama review with installed-model checks, fixed loopback transport, disabled redirects/proxies, and bounded generation. Codex/Claude are optional cloud CLI contracts; Gemini detection is available but invocation remains disabled pending verification.
- Provider-bound one-use cloud preview consent, private identity mappings, independent rejection of unsupported model findings, and advisory-only static explanations.
- Read-only Windows signature checks for sampled candidates, excluding Downloads; no AI-triggered malware scans or executable model instructions.
- Regression tests for redaction, consent, unsupported outputs, tool restrictions, and provider failure boundaries.
- Exclusive Windows loopback binding prevents two monitors from accidentally serving the same port.

## 0.3.0 — guided local use, unpublished

- Three-step start panel, automatic OS/architecture and assistant CLI detection, clear inactive-history wording, and advanced full-scan controls.
- Privacy-safe AI handoff preview for any assistant, without automatic connections or uploads; active versus historical versus unknown threat counts in summary exports.
- Explicit quick/selected one-shot scan CLI for authorized local assistants; results are redacted, with unavailable/unverified states preserved.
- Native binaries open their dashboard by default; source launchers prefer their virtual environment and explain missing dependencies. Legacy monitor links are verified before reopening.
- No monitor replacement, automatic scan, public push, or deployment.
