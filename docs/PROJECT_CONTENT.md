## Feature copy

**Understand unusual activity.** A small local learning model compares process connections with observed behavior and explains its review signals. It does not replace a malware verdict or silently remove files.

**Use your installed AI tools.** Ask an Ollama model to review anonymous security indicators locally. Optional Codex, Claude and Gemini adapters, compatible model servers, and trusted inference wrappers expand your choices. Test a connection with fictional evidence first. Cloud reviews require explicit consent and an evidence preview. Unsupported model results remain unverified; AI output never runs commands.

**Use the engine your platform supports.** Windows integrates with Defender. Linux and macOS can scan selected folders with ClamAV. Controls adapt to installed tools and available permissions.

**Keep private details out of shared reports.** Identifiers, paths, command lines, addresses, SSIDs, tokens and raw evidence are excluded from summary exports. Sharing is your decision; nothing uploads automatically.

**See your Wi-Fi with clear limits.** Discover responding local devices, distinguish cached entries, and review a small set of router services. Silent devices and firmware vulnerabilities remain outside these checks.

## FAQ copy

**Is Sentinel Local an AI antivirus?** It is an AI-assisted security companion. Windows Defender supplies its own machine-learning malware protection, while Sentinel adds explainable local statistical behavior analysis. Sentinel itself is not an independently validated malware classifier.

**Does it send files to a cloud AI provider?** Sentinel sends no file contents or raw evidence. Local Ollama is the default. Optional vendor adapters and explicitly trusted profiles receive anonymous counts and indicator flags only after consent. Custom wrappers have permissions chosen by their owner and must be verified separately. Existing native engine cloud policies and definition updates remain controlled by those tools.

**Does Linux or macOS get automatic real-time blocking?** No. Sentinel supplies monitoring and optional ClamAV folder scans there. Platform-native and separately configured protections remain responsible for prevention.

**Can a successful test prove a computer is clean?** No. Tests validate behavior and integration within stated coverage. Missing permissions, skipped content, sampling gaps and unknown threats remain possible.

**Where are the downloads?** Unsigned desktop beta artifacts and checksums are listed in the repository releases. Signed consumer distributions remain pending native validation and signing.
